# 飞书表格与视图

## 1. 统一任务队列

字段：

- D1任务ID
- 任务类型
- 标题
- 所属部门
- 状态
- 主负责人
- 协作者
- 优先级
- 截止时间
- 客户/订单摘要
- 详情链接
- D1版本
- D1更新时间
- 同步状态
- 同步错误摘要

视图：

- 公共队列
- 我的任务
- 我协作的任务
- 团队负责人视图
- 今日到期
- 已逾期
- 同步异常

## 2. 员工角色镜像

字段：

- D1员工ID
- 飞书用户
- 姓名
- 部门
- 团队
- 角色列表
- 是否负责人
- 是否启用
- D1权限版本
- 最后同步时间

该表只用于展示和校验，不作为正式权限主库。

## 3. 队列配置

字段：

- 任务类型
- 默认部门
- 默认团队
- 默认优先级
- 处理时限
- 领取权限
- 分派权限
- 提醒提前量
- 逾期升级规则
- 是否启用

## 4. 同步异常

字段：

- 异常ID
- D1实体类型
- D1实体ID
- 飞书记录ID
- 操作
- 失败原因
- 尝试次数
- 首次失败时间
- 最近失败时间
- 下次重试时间
- 是否需要人工处理
- 处理人
- 处理备注

## 5. 数据最小化

任务标题和摘要不得包含：

- 完整微信号；
- 完整支付截图内容；
- 返款账户信息；
- 内部利润；
- 其他客户名称；
- 账号密码或 Session。
