# 飞书匿名 PoC 规格（最终外部激活，非 M8 本地任务）

> M8 只交付本地 mock/adapter、严格合同、dry-run 和 Runbook。本文件中的真实飞书操作必须由业务所有者在单独授权后执行；当前分支没有创建应用、调用 API、配置回调、写入生产 D1 或部署。

## 1. 目的

在连接真实 Cloudflare 资源和真实数据前，验证当前飞书版本和管理员权限是否满足员工工作台需求。

## 2. 匿名数据

只能使用：

- 测试员工 A/B/C；
- 测试买家 B001；
- 测试卖家 ido-example-1；
- 测试订单 JP-TEST-001；
- 虚构 ASIN 和图片。

禁止真实微信号、订单号、金额、客户名和截图。

## 3. 验证项目

1. 创建自建应用。
2. 员工 OAuth。
3. 获取用户身份。
4. 多维表格记录创建、更新、查询。
5. 任务公开队列。
6. 员工领取任务。
7. 负责人分配/改派。
8. 协作者。
9. Todo 或机器人提醒。
10. 手机端打开 Cloudflare 测试详情链接。
11. 回调签名和事件去重。
12. 权限不足时拒绝。
13. API 限流/失败后的重试。
14. 表格字段和视图可由管理员维护。

## 4. 通过标准

- 每名员工可被唯一识别。
- 同一任务只能成功领取一次。
- 普通员工不能跨团队改派。
- 负责人只能管理本团队。
- 飞书失败不破坏 D1 权威状态。
- 回调重复不会产生重复事件。
- 手机和桌面均能打开详情页。
- 当前免费版或已选版本的 API、记录和权限能力经过实际验证并记录。

## 5. 输出

PoC 完成后必须生成：

```text
FEISHU_POC_RESULT.md
```

包含：

- 应用类型；
- API 权限；
- 表格能力；
- 回调能力；
- 实测限制；
- 失败项；
- 是否允许进入正式联调。
