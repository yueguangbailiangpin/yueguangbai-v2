# 飞书与 Cloudflare 边界

## 1. 飞书负责

- 员工登录入口和身份来源；
- 公共任务队列、我的任务、团队任务视图；
- 负责人、协作者、优先级、截止时间和内部任务备注；
- Todo、机器人提醒和逾期提醒；
- 当前业务摘要；
- 打开 Cloudflare 受控详情页的链接；
- 同步异常的人工处理视图。

## 2. Cloudflare 负责

- 所有客户和业务主数据；
- 权限和字段投影；
- 编号池；
- 状态机；
- 幂等和并发；
- 产品、需求、预约和订单；
- 评论和财务；
- 审计；
- 图片 Manifest；
- 飞书任务权威记录；
- 同步 Outbox。

## 3. 飞书不得保存为权威事实的内容

- 完整订单；
- 订单财务快照；
- 买家返款账本；
- 卖家本金和服务费账本；
- 利润；
- 全量客户隐私；
- 完整微信聊天；
- 正式图片原件；
- 编号池；
- 订单号认领。

## 4. 可在飞书直接编辑的字段

- 主负责人；
- 协作者；
- 优先级；
- 截止时间；
- 内部任务备注；
- 任务领取/放回队列/转派请求。

这些修改必须回调 D1，通过版本检查成功后才生效。

## 5. 只能在受控 Web 页面完成的动作

- 激活或停用客户；
- 身份冲突处理、合并和微信号变更；
- 新品审核和创建正式产品；
- 发布需求；
- 预约批准/拒绝；
- 确认正式订单；
- 评论审核；
- 返款和结算；
- 冲正和更正；
- 财务导出；
- 权限管理。

## 6. 摘要最小化

飞书任务默认仅展示：

- 业务流水号；
- 客户编号或脱敏名称；
- ASIN/店铺摘要；
- 任务状态；
- 截止时间；
- Cloudflare 详情链接。

只有具备权限的员工打开详情页后才能查看完整客户信息。
