# V2 产品与业务规则

## 1. 沟通和正式事实

私人微信负责日常沟通、提醒和关系维护。

以下内容必须通过门户或内部受控页面成为正式事实：

- 产品申请和需求批次；
- 预约；
- 订单号、订单日期、最终支付金额和截图；
- 评论资料和审核结果；
- 买家返款；
- 卖家本金、服务费和结算；
- 财务更正、冲正；
- 客户身份变更和账号启停。

门户第一版提供问题反馈和资料补充，不开发完整实时或多轮客服聊天。

## 2. 客户模型

- 一个卖家客户对应一个卖家组织。
- 一个卖家组织可以有多个成员。
- 一个卖家通常有 5–20 个店铺。
- 店铺归属固定，不因员工或成员调整而改变。
- 一个 ASIN 在同一 Marketplace 只能属于一个权威店铺。
- 第一版 Marketplace 为 JP，但表结构必须显式包含 Marketplace。

## 3. 产品与需求

产品是长期主数据，需求批次是一次数量计划，两者不能混用。

### 产品申请

卖家成员提交：

- 店铺；
- ASIN/产品编号；
- 产品中文名；
- 搜索词；
- 产品链接；
- 图片；
- 备注。

审核结果：审核中、通过、拒绝、撤回。

### 需求批次

产品通过后，卖家另行提交需求批次。批次至少包含：

- 产品；
- 目标数量；
- 任务/评论类型；
- 开放时间；
- 预约截止时间；
- 下单截止时间；
- 买家可见说明；
- 内部说明；
- 状态。

追加需求必须新建批次，不覆盖旧批次。

## 4. 预约

买家只能看到已发布的公开需求。

预约流程：

```text
买家提交预约
→ 系统预检
→ 暂时记录候选
→ 售前人工批准或拒绝
→ 批准后锁定名额
→ 买家在期限内提交订单资料
```

预检至少检查：

- 买家启用状态；
- 买家身份是否待人工核对；
- 相同需求/ASIN历史参与；
- 有效名额；
- 当前截止时间；
- 既有未完成预约；
- Marketplace。

领取、批准、取消、过期和重开必须有状态事件。

## 5. 待核对订单资料与正式订单

买家提交的订单信息先进入“待核对资料”，不是正式订单。

必须提交：

- Amazon 订单号；
- 订单日期；
- 最终实际支付金额（JPY）；
- 订单截图；
- 可选备注。

售前确认后才：

- 认领订单号；
- 生成或确认订单组；
- 首次正式订单时生成买家编号；
- 锁定买家日汇率；
- 锁定卖家协议汇率版本；
- 锁定服务费规则版本；
- 保存产品、店铺、卖家、买家和需求快照；
- 生成正式订单和审计事件；
- 更新需求批次进度。

同一订单号正常只认领一次。少数历史同订单号跨店铺情况必须进入人工冲突处理，不自动复制。

## 6. 金额和汇率

### 最终支付金额

订单权威金额为订单截图显示的最终实际支付金额，币种 JPY。

### 买家日汇率

- 方向：`1 JPY = X CNY`
- 每个中国业务日期一条；
- 不允许使用缺失日期的前一天或最近值自动回退；
- 正式订单确认时保存快照；
- 历史快照不受后续修改影响。

### 卖家协议汇率

- 属于卖家组织，不属于产品；
- 同一卖家组织所有产品默认使用同一协议；
- 版本化；
- 卖家对接提交变更，管理员确认；
- 仅影响生效后的新正式订单。

### 服务费

- 规则键：卖家组织 + 任务/评论类型；
- 类型至少：rating、text、image、video；
- 版本化；
- 正式订单时锁定规则版本；
- 评论审核通过时生成应收服务费事实。

## 7. 评论与原业务模式

按业务所有者决定保留原模式：

```text
评论资料提交
→ 售后审核
→ 审核通过
→ 买家返款变为应付
→ 卖家服务费变为应收
```

系统只管理内部流程，不自动操作 Amazon 账号、评论发布、修改或删除。

评论状态只能通过评论工作流修改。审核通过必须在同一业务命令中：

- 校验状态和版本；
- 保存审核事件；
- 锁定评论类型；
- 生成买家返款应付；
- 生成卖家服务费应收；
- 创建飞书任务/Outbox；
- 返回可重放结果。

审核通过后的更正必须使用更正单，明确选择保留或冲正已产生的财务事实。

## 8. 买家返款和卖家结算

### 买家返款

应返金额基于订单快照。实际转账由售后录入：

- 应付金额；
- 实际金额；
- 差额（系统计算：实际 - 应付）；
- 转账时间；
- 凭证；
- 备注。

已完成记录不可直接编辑或删除。

### 卖家本金和服务费

本金与服务费是两个独立结算组件：

- 本金应付/已结算/无需结算；
- 服务费未产生/应付/已结算/无需结算。

卖家门户只能看到其组织和授权店铺的卖家侧金额。

### 内部结算与利润

至少提供：

- 预计利润；
- 财务已完成利润；
- 内部已结算利润；
- 现金差额；
- 最终实现利润。

所有报表都由不可变财务事实聚合，不允许用户直接填写利润。

## 9. 图片

- R2 是正式在线图片源。
- 图片通过授权 API 读取，不公开裸 R2 Key。
- 客户可见性按图片种类、客户组织和字段白名单决定。
- 买家返款凭证、私人微信截图和内部备注默认不可见给卖家。
- 第一版不从 Google Drive 实时回源。
